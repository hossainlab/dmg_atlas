Generated by `scripts/12_package_v1.py` from the files themselves (field list, dtype, categories, missing counts). `source` names the pipeline phase that produced the field; author columns are copied verbatim from the deposits.

## 1. `data/processed/atlas_core.h5ad` (tumour + microenvironment reference)

- Shape: 311,618 obs x 18,882 var.
- layers['counts']: shape (np.int64(311618), np.int64(18882)), dtype int32.
- obsm['X_scanvi']: shape (311618, 30), dtype float32.
- obsm['X_scvi']: shape (311618, 30), dtype float32.
- obsm['X_scvi_malignant']: shape (311618, 30), dtype float32.
- obsm['X_umap']: shape (311618, 2), dtype float32.
- var columns: highly_variable, highly_variable_nbatches, highly_variable_rank, hvg_seurat_v3_medianrank_first, means, symbol, variances, variances_norm; var index = symbol.
- uns keys: hvg, leiden_scanvi_r1, phase4, umap.

Notes: `X` is intentionally empty (counts live in `layers['counts']` to keep the file < 6 GB); set `adata.X = adata.layers['counts']` before normalising. obs index = `<sample_id>:<original barcode/cell id>`. var index = GRCh38-2020-A canonical symbol (18,882 genes measured in every UMI sample).

## 2. `data/processed/query_mapping.h5ad` (projected queries)

- Shape: 224,377 obs x 3,000 var.
- X: csr_matrix (np.int64(224377), np.int64(3000)), dtype int32.
- layers['counts']: shape (np.int64(224377), np.int64(3000)), dtype int32.
- obsm['X_scanvi']: shape (224377, 30), dtype float32.
- obsm['X_umap_ref']: shape (224377, 2), dtype float32.
- obsm['scanvi_probs']: shape (224377, 7), dtype float32.
- obsm['scanvi_probs_pre_audit']: shape (224377, 7), dtype float32.
- var columns: symbol; var index = symbol.
- uns keys: phase5.

Notes: `X` = `layers['counts']` = reference-HVG count matrix per query (UMI for Braun/Siletti; round(RSEM) for Liu; TPM-derived pseudo-counts for Filbin/LaBelle — see docs/phase5_mapping_notes.md). Query cells never enter the reference model; labels are scANVI predictions.
