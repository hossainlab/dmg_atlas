Code: `src/dmg_atlas/cnv.py`; CLI `scripts/05_cnv_calls.py --study <name>` (one study per process), `scripts/06_cnv_aggregate.py`.
Log: `logs/phase3_cnv.log` (wall time + peak RSS per sample and step; the log also records the benchmark iterations that led to the final design).
Outputs: `data/processed/malignant_calls.csv` (one row per cell, 342,213 cells), `results/tables/malignant_calls_per_sample.csv`,

- Normalisation: UMI/RSEM `normalize_total(1e4)+log1p`; Filbin linear TPM `log1p(TPM/10)`; **LaBelle tables are already log2(TPM/10+1)** (per-cell maximum 9–12.4; Filbin's linear tables give log2 maxima of 12.5–13.6), detected by `max < 30` and rescaled by ln 2. Phase 2 notes describing LaBelle as linear TPM were wrong for the SS2 tables as well as P9.

## Gene positions and arms
- GENCODE v32 (GRCh38.p13 / Ensembl 98, the annotation behind the cellranger 2020-A universe), `data/external/gencode/gencode.v32.annotation.gtf.gz` (md5 6e5ca615187dfe3775a98e406fed69e4, downloaded from ftp.ebi.ac.uk, 60,609 gene records; cached as `gene_positions_gencode_v32.csv`). Genes matched by Ensembl ID first, symbol second.
- Arm boundaries: approximate GRCh38 centromere intervals typed from memory of the UCSC hg38 cytoBand table (hgdownload.soe.ucsc.edu is blocked by the sandbox allowlist; not retrieved). `validate_arm_boundaries()` shows every midpoint lies inside a protein-coding gene-free gap of the GTF (≥ 2.8 Mb; `arm_boundaries_grch38_validation.csv`), so no gene's arm depends on the exact coordinate; acrocentric chromosomes (13, 14, 15, 21, 22) are entirely `q`. 4q12 = chr4:52.7–59.5 Mb (PDGFRA 54.23 Mb, KIT 54.66 Mb inside) is no longer a hallmark event (audit CNV-03; see corrections).

## Method
1. **Marker scores** (`sc.tl.score_genes`, log-normalised): myeloid, T_NK, oligodendrocyte, vascular, neuron, astrocyte (AQP4/GFAP), OPC-like, AC-like, MES-like, cycling (gene lists in `cnv.py`).
   `marker_call`: *normal* if the best normal type scores ≥ 0.25, beats its type-specific tumour competitor by 0.10 (myeloid vs OPC/MES — microglia express APOE/CLU; oligodendrocytes vs AC/MES — they express OLIG1/2, SOX10; vascular vs OPC/AC — pericytes express VIM/CD44/ANXA1) and ≥ the astrocyte score; *astrocyte_like* if astro ≥ 0.25 and > OPC-like + 0.10; else *malignant_candidate*. Reference candidates = normal cells with score ≥ 0.5 and ≥ 2× the second-best normal type. Thresholds were set on jessa_scrna P-6337 against author labels (Immune 2,626/2,963 normal, Oligodendrocytes 52/55, Vascular 126/167).
2. **inferCNV** (`run_infercnv` imports infercnvpy's `_running_mean_by_chromosome` and reproduces the rest of its arithmetic in-process; infercnvpy's `process_map` uses a ProcessPool that this sandbox forbids): genes expressed in ≥ 10 % of cells and autosomal (5.1k–12.1k per study), deviation from the reference mean clipped to ±3, pyramidal running mean over 100 genes every 10 genes, median-centred per cell, noise filter |x| < 1.5 SD → 0. Two smoothed matrices are built from the same deviations and reference choice: `X_cnv` with the **chromosome** as smoothing unit (drives `cnv_score` = mean |x|, clustering and heatmaps) and, since the audit, `X_arm` with the **chromosome arm** as smoothing unit (no window straddles a centromere; drives the arm means for all 39 autosomal arms, chr2, chr7; arms with < 10 used genes are not evaluable). The noise threshold estimated on `X_cnv` is applied to both.
   **Reference** (the part that required several iterations, all logged): the sample's own immune candidates (myeloid, T_NK) + a *pooled immune anchor* (≤ 300 cells/type from the other samples of the same study and assay stratum) + *pooled lineage references* (oligodendrocyte / vascular / neuron candidates from the other samples, ≤ 50 per donor sample per type, ≤ 300 per type, after a per-sample purge of candidates sitting in tumour-grade CNV clusters: score_rel ≥ 0.02 or hallmark z ≥ 5). A sample's own glial/neuronal candidates are never used as reference. Per-cell MAD refinement (cnv_score > median + 3 MAD removed). Each cell's deviation is computed against **every** reference category and the category with the smallest residual is kept (`cnv_best_ref`, "best-match" baseline) instead of infercnvpy's min/max envelope across categories.
3. **CNV clusters and calls**: PCA (30) → kNN (15) → Leiden (res 1.0, igraph) on the CNV matrix. Reference statistics from the final reference cells. Cluster = *malignant* if mean cnv_score > ref mean + 0.008, OR one hallmark event with z ≥ 2 (z = (cluster mean − ref mean)/max(ref SD, 0.01), expected direction), OR two events with z ≥ 1; clusters with ≥ 20 % reference cells need both a score elevation and an event. Hallmark set: chr1q gain, chr2 gain, chr7 gain, chr13q/14q/10q/17p loss (4q12 gain removed by the audit). Event flags are inherited from the cluster (subclone level). Because the noise filter runs before reference statistics are taken, reference arm SDs sit at the 0.01 floor, so 'z ≥ 2' is in practice an absolute arm deviation ≥ 0.02 log units (audit CNV-10). Each malignant cluster carries `cnv_confidence` = *event_backed* (hallmark event) or *score_only* (score elevation alone); samples with < 100 windows or < 3,000 used genes are flagged `low_confidence_sample`.
4. **Consensus** (`consensus_call`): tier 1 author label (mapped to malignant/normal), tier 2 `cnv_call`, tier 3 = CNV and marker agree (astrocyte-like cells follow the CNV call, but need a hallmark event to be called malignant) and, where an author label exists, the author agrees; otherwise *ambiguous*. `consensus_celltype_coarse`: malignant | myeloid | T_NK | oligodendrocyte | astrocyte | neuron | vascular | other | ambiguous. A sensitivity label `consensus_call_eventtrust` additionally trusts marker-normal cells that sit in an event-backed CNV-malignant cluster (when no author label contradicts); it is not used by `consensus_call`.

## Why this reference design (benchmark against Jessa author labels, all in `logs/phase3_cnv.log`)
| design | failure |
|---|---|
| own marker-based reference incl. oligodendrocytes (infercnvpy envelope) | OC-like tumour cells score as oligodendrocytes and flatten the baseline: Zang 521 malignant of 6,579; Jessa P-6519 recall 0.14, P-6328 0.02 |
| immune-only own reference | near-pure tumours have tumour cells among "immune" candidates (P-6328: 185 myeloid-scoring cells, all author-malignant; P-4504 recall 0.27) |
| + pooled study immune anchor | fixes the above (P-6328 1.0, P-4504 1.0), but normal oligodendrocytes/neurons/astrocytes in nuclei deviate from an immune baseline (hallmark z 3–5): Okada 2054_thalamus precision 0.14, Jessa multiome P-1694 0.25 |
| + own-sample lineage candidates admitted after purge | tumours with weak CNV cannot be purged; admitted tumour "oligodendrocytes" kill the signal (P-6328 0.02 again) |
| + pooled lineage categories under the min/max envelope | the envelope widens with the per-gene sampling noise of every 50–200-cell category (P-6519 0.97 → 0.57 after adding 51 vascular cells) |
| best-match baseline + pooled purged lineage (final) | benchmark-subset iterations ran on 22 samples (9 jessa_scrna, 7 okada, 4 jessa_multiome, 2 collot; `logs/phase3_cnv.log` 17:03–17:16). The log records no recall/precision; the delivered pipeline gives tier-2 agreement 0.915 (sample median 0.932) on the 9 Jessa scRNA benchmark samples. An earlier version of this row quoted 'recall 0.986 / precision 0.973', which is not reproducible from any delivered output and has been withdrawn (audit CNV-06). |
| + pooled astrocyte category | dominated by AC-like tumour cells; masked AC-like tumour (Jessa snRNA samples 0.88 → 0.69) → removed; normal astrocytes are handled by the consensus rule instead |

## Deviations / caveats
- UCSC cytoBand not downloaded (allowlist); centromere coordinates typed from memory but validated as lying in gene-free gaps (above).
- infercnvpy's multiprocessing replaced by an in-process loop and its envelope reference replaced by the best-match baseline (documented above); the smoothing arithmetic is infercnvpy's (its running-mean function is imported). The best-match baseline keeps, per cell, the reference category with the smallest residual, which shrinks the signal of every cell slightly (reference cells are included in their own category mean with ≤ 10 % self-weight), and the MAD refinement removes high-score reference cells after the category means were computed; both effects are conservative for calling and were left unchanged (audit CNV-11).
- Thresholds (marker 0.25/0.10/0.5, score_rel 0.008, z 2/1, purge 0.02/5) were set during benchmark iterations on 22 samples — 9 jessa_scrna (P-1713, P-3407, P-4198, P-4504, P-6254, P-6328, P-6337, P-6519, P-6640), 7 okada (1006_thalamus, 1428_pons, 1734_pons, 1890_pons, 1963_pons, 2054_thalamus, 586_pons), 4 jessa_multiome (P-1694, P-1701, P-1779, P-6253) and 2 collot (DMG-PMC-9_edge, PMC-DMG-7) — using author labels of all four studies (the cluster-level threshold table also includes Liu clusters), then applied unchanged to all studies. Agreement on those 22 samples is therefore not a blind test; the held-out 75 samples give the same or higher agreement (above). The marker thresholds were set on jessa_scrna P-6337_S-8821 (an earlier code comment naming P-6251 was wrong).
- Doublets (`predicted_doublet_fixed`) are not removed; cycling cells are not treated specially.
- scpca SCPCS000637: no reference → all `unassigned`/ambiguous; LaBelle has no malignant author labels (immune-only, all 6,366 in the single low-complexity sample P9) so it is not a validation gate; P9 is flagged `low_confidence_sample`.
- Event frequencies are cluster-inherited; per-cell arm means (`arm_1q`, …, from the per-arm matrix) are in `malignant_calls.csv` for finer analyses; `arm_4q12` is NaN wherever no per-arm window midpoint falls inside the band (most samples).
