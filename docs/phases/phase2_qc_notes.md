# Phase 2 — per-study ingest, QC and gene harmonisation (2026-10-17)

Code: `src/dmg_atlas/{utils,genes,ingest,qc}.py`, CLI `scripts/03_ingest_qc.py --study <name>`, driver `scripts/run_phase2_all.sh`, report `scripts/04_qc_report.py`.
Config: `configs/qc.yaml`. Log: `logs/phase2_qc.log` (wall time + peak RSS per sample/step), `logs/phase2_driver.log`.
Outputs: `data/interim/<study>.qc.h5ad` (atlas samples), `data/interim/<study>.outgroup.qc.h5ad` (jessa_scrna, desisto), `results/qc/qc_report.md`, `qc_per_sample.csv`, `qc_per_study.csv`, `gene_harmonisation.csv`, `genes_shared_all_umi_studies.csv`, `sanity_jessa_malignant_qc.csv`, `qc_violin_<study>.png`.
Environment: conda `multiverse` (scanpy 1.11.5, anndata 0.12.19); `scikit-image` and `psutil` were added (scanpy's scrublet needs skimage for threshold detection).

## Headline numbers
- 119 atlas samples (10 studies), **420,381 cells/nuclei before QC → 357,061 flagged `qc_pass` (84.9 %)**; out-group files 127,949 → 99,360. *[superseded 2026-10-19 by DQ-04 — the author-prep-aware mitochondrial rule drops 655 Liu frozen nuclei, so the current headline is **356,406 `qc_pass` (84.8 %)**; see Audit corrections 4 below. Out-group unchanged.]*
- "Before QC" exceeds the 334,439 author-QC cells of the Phase 1 manifest because GEO deposits of Jessa (both series) are cellranger *filtered* matrices containing barcodes the authors later removed (18,210 scRNA + 39,652 multiome barcodes carry no author metadata) and the Liu raw tables contain cells absent from the postFilter metadata. All barcodes are kept with `author_qc_pass` / `author_postfilter` flags.
- Harmonised gene universe = GRCh38-2020-A symbols (36,591 unique). **18,882 genes are measured in every sample of all 7 UMI studies**; 14,119 across all 10 studies (TPM cohorts included).
- Peak RSS: 8.95 GB (jessa_multiome: 20k-nucleus samples × 60,658 features + scrublet), 8.45 GB (okada), ≤ 5.9 GB elsewhere. Wall: jessa_scrna 6.2 min, okada 5.8, jessa_multiome 3.2, collot 0.9 (incl. streaming 292 M MTX entries), rest < 0.5 min; whole phase ≈ 20 min of compute. Okada's 8.45 GB slightly exceeded the ~8 GB target: the chunked reader is fine (≈2 GB/sample), the peak is the vstack of 22 int32 CSR blocks (2.5 GB) + copies during concat/write.

## Object layout (all `.qc.h5ad`)
- `X` and `layers['counts']` hold the same int32 CSR matrix (UMI; Liu = RSEM expected counts in float32, 25–31 % fractional values). TPM cohorts (Filbin, LaBelle) have `layers['tpm']` only (float32), `X` = same.
- obs: manifest columns (`sample_id, patient_id, study, role, assay, chemistry, site, age_years, age_group, h3_variant, k27m_status, sex, treatment, tissue_timing, include_in_atlas, exclusion_reason, counts_type, label_source`), `original_cell_id`, QC (`n_counts, n_genes, pct_mito, pct_ribo, pct_hb, qc_pass, qc_fail_reason, qc_assay_class, qc_min_genes, qc_max_genes, qc_pct_mito_max, doublet_score, predicted_doublet, predicted_doublet_fixed`), and author columns prefixed `author_` (never modified).
- obs index = `<sample_id>:<original barcode/cell id>`.
- var index = canonical symbol; `ensembl_id` (2020-A ID, NaN for symbols only reachable via alias), `n_samples_measured`, `measured_in_all_samples`. Genes absent from a sample's deposited feature list are **zero-filled** by the outer join (only matters for LaBelle 14,642 vs 19,357 gene tables and Liu's 23,686 vs 32,617 gene files) — use `measured_in_all_samples` or intersect before modelling.
- `uns['phase2']` = study, QC config snapshot, universe description.

## Decisions
1. **Thresholds** (configs/qc.yaml): nuclei (snRNA, multiome_RNA) pct_mito < 5 %, cells (scRNA) < 20 %, Smart-seq2 < 20 %; min genes 300 (10x) / 1000 (SS2); per-sample max genes = 99.5th percentile of `n_genes`; a NaN pct_mito (zero-count barcode) fails. Nothing is removed — `qc_pass` is a flag.
2. **Scrublet** per 10x sample on cells with ≥ 300 genes, expected rate 0.06, seed 0, after pre-selecting 3,000 seurat_v3 HVGs (memory guard: scanpy's scrublet densifies; without it a 7k-cell sample peaked at 4.7 GB). The **automatic threshold is unreliable here**: per-sample thresholds ranged 0.03–0.71 (per-study medians 0.19 ScPCA to 0.63 Zang) and it called 0 doublets in most samples (median per-sample rate 0.000; pooled rates 0.1–8 % driven by a few samples). `predicted_doublet_fixed` (= score > 0.25) gives 0.1–2.6 % per study (DeSisto 0.1 %, Zang 0.5 %, Okada 2.6 %) and is the column Phase 3 should use (or re-run scDblFinder); `doublet_score` is stored for all cells. Doublets are flagged only.
3. **Gene harmonisation** (genes.py docstring): reference = union of 10x feature files (2020-A/zang, cellranger-arc 2020-A/jessa_multiome, GRCh38-3.0.0/desisto, hg19-1.2.0/jessa_scrna) + ScPCA Ensembl 104; canonical symbol per Ensembl ID from the newest source; universe = 2020-A symbols. Ensembl-ID mapping where features provide IDs; symbol-only studies use exact match then alias (same Ensembl ID, older symbol; symbols duplicated within a source such as hg19 `5S_rRNA` or ScPCA's placeholder `snoZ196` are excluded from aliasing); ambiguous symbols dropped; duplicates after mapping summed. Reference tables cached in `data/interim/gene_reference.csv`, `gene_universe.csv`. Losses: Filbin 4,007 unmapped (hg19 pseudogenes/`-AS1` names absent from 2020-A), Liu 1,749 for the 32,617-gene files and 4,007 for the 23,686-gene files (two annotations in the deposit), jessa_scrna 1,891 (Ensembl IDs retired since hg19), jessa_multiome 60,658 → 34,256 (GENCODE v32 lncRNAs outside 2020-A), ScPCA 60,319 → 36,457, Collot 0 (author-filtered 19,248 all exact).
4. **Collot**: the Zenodo matrix holds 146,567 cells (24 re-processed Jessa samples + 5 new); streamed once (pandas chunks of 20 M MTX lines) keeping only `Study == This_study`, cached to `data/interim/collot_this_study_counts.h5ad` (0.45 GB). The 24 Jessa copies are not processed (not an out-group; the GEO originals are used).
5. **Okada**: counts recovered per sample from `raw.X` (CSR, contiguous rows per sample) as round(expm1(x)·nCount_RNA/1e4); for all 22 samples max |x − round(x)| ≤ 1e-12 and row sums equal `nCount_RNA` exactly (asserted; see log). Author QC (200 < nFeature < 5000, mito < 5 %) was already applied: 95.5 % pass ours.
6. **Liu**: raw cell IDs harmonised to metadata format with regex `[-_]P(\d+)[-_]?([A-H]\d{2})` → `<sample>.P<plate>.<well>` using `liu_rawfile_to_sample.csv`; 8,984/9,248 postFilter cells recovered (missing: SUDIPG55 129, ICGCGBM96 62, SUDIPG67 58 — no raw file, pSCG1 10, S1D2E3H7 5). Duplicated harmonised IDs (MUV82: `MUV82Nuc-P3` vs `MUV82-P3`, 96 columns) resolved by keeping the larger library. 42 of 43 manifest samples written (SUDIPG67 has no raw counts). SUDIPG52 raw file has no metadata and is not in the manifest → not ingested. Values are RSEM expected counts (float). Liu contains frozen *nuclei* samples labelled `smartseq2`; their QC class is smartseq2 (mito < 20 %), use `author_prep` if nucleus-specific handling is needed.
7. **Filbin / LaBelle TPM tables contain no MT- genes** → pct_mito = 0 everywhere; only the gene-count filters act (99 % pass). LaBelle P9 is a 10x library distributed as per-cell CPM (nCount_RNA = 1e6), stored in `layers['tpm']`; UMI counts are not recoverable. LaBelle SS2 cells come from two tables (tumour, immune) with different gene lists (14,642 vs 19,357) → zero-filled union; `measured_in_all_samples` marks the 14,487 common genes.
8. **ScPCA** `filtered_rna.h5ad` is dominated by low-count droplets: SCPCS000636 has **0** barcodes with ≥ 300 genes and SCPCS000637 keeps 441 (median 362 genes). The ScPCA `processed` objects kept 51/1,363 cells for the same reason. Phase 3 should expect to drop SCPCS000636 and treat SCPCS000637 as low-quality.
9. **Jessa multiome** GEO matrices contain 86,978 barcodes vs 47,326 author nuclei; 63 % pass ours. Multiome RNA is intron-inclusive nuclear RNA with higher ambient mito.

## Sanity checks
- (a) Jessa author-labelled malignant cells passing our QC: scRNA atlas 69,593/71,899 (96.8 %), multiome 33,975/35,122 (96.7 %), scRNA out-group 87.3 %. Author-normal cells: 96.7 % / 85.2 %. Barcodes without author metadata pass ours at 38 % / 27 % — expect them to be mostly empty/ambient/low-quality; `author_qc_pass` should be preferred as the inclusion flag for Jessa in Phase 3.
- (b) Median pct_mito by class (UMI studies, before QC): cells 2.7–44.9 % (median 13.5), nuclei 0.0–47.7 % (median 0.48). **Six nucleus-labelled Jessa samples have median mito > 5 %**: P-6254_S-8499 (47.7 % over all barcodes, 10.6 % over author-QC nuclei → only 24 % of author nuclei pass the 5 % rule), P-1779_S-1781 multiome (15.2 % / 5.1 %, 49.5 % of author nuclei pass), P-6253_S-8498 multiome (11.2 % / 3.1 %, 67 %), P-1709_S-1709 multiome (5.9 % / 3.4 %, 100 %), and two out-group scRNA samples (P-3200_S-3867 11.5 %, P-5613_S-7162 5.4 %). The author `Technology` column confirms the nuclear protocol; the authors used sample-specific mito cutoffs. Our pct_mito equals the authors' `percent.mito` to 2 decimals, so the discrepancy is thresholding, not computation. Decision for Phase 3: for these samples, treat `author_qc_pass` as the QC gate (or relax mito to 10 %) rather than losing 76 % of P-6254's malignant nuclei.
- (c) 18,882 harmonised genes shared by all UMI studies (`results/qc/genes_shared_all_umi_studies.csv`).

## Pitfalls for later phases
- Never read `okada.qc.h5ad` with `X` densified (168,597 × 36,591). Read `layers['counts']` sparse or in backed mode.
- `n_counts` for TPM cohorts is 1e6 by construction; use `n_genes` only.
- Out-group files (`jessa_scrna.outgroup`, `desisto.outgroup`) use the same var/universe and may be concatenated for marker-gene contrasts but must not enter the atlas reference.
- Collot's 5 samples are the only ones with `assay == snRNA` *and* 10x v3 single-nucleus chemistry from a non-Jessa lab; its `author_celltype` uses Collot's own vocabulary (AC_like, OPC_like, ...).
- Filbin and Liu share 7 patients (manifest `patient_id`); do not treat as independent replicates.


## Audit corrections (2026-10-19; findings DQ-01, DQ-03, DQ-04, DQ-06, DQ-09, DQ-12, DQ-20, DQ-13 of docs/audit/data_qc_audit.md)

The sections above are kept as written on 2026-10-17; the statements below supersede them. Code: `src/dmg_atlas/qc.py` (`sample_gate`, `mt_genes_present`, author-prep-aware mito rule), `src/dmg_atlas/ingest.py` (`iter_labelle`), `configs/qc.yaml` (`sample_gate`, `author_prep_aware`), `scripts/04_qc_report.py`. Only `labelle` and `liu` were re-ingested (`03_ingest_qc.py`); the 105 per-sample rows of the other eight studies are unchanged (verified cell by cell against `results/qc/qc_per_sample.pre_audit.csv`). Previous outputs are kept as `*.pre_audit.*`; log `logs/fix_data_repro.log`.

1. **LaBelle value scale (DQ-01).** All three GSE227983 tables (tumor_ss2, immune_ss2, immune_tenx) are **log2(TPM/10+1)**, not linear TPM: per-cell maxima 7.6–9.0, column sums 3.7k–12.6k, 100 % fractional values. The layer is now `layers['log2_tpm10']` (was `layers['tpm']`) and `uns['value_scale']` records the scale; `uns['value_scale']` is also set for Filbin (`linear TPM (RSEM; per-cell sum 1e6)`). Decision 7's sentence "P9 is a 10x library distributed as per-cell CPM (nCount_RNA = 1e6)" is **false**: P9 is distributed on the same log2(TPM/10+1) scale (median per-cell sum 3,244) and UMI counts are not recoverable. `n_counts`/"median counts" are meaningless for Filbin/LaBelle and are shown as n/a in `qc_report.md`. Downstream readers (`05_cnv_calls.py`, `10_prepare_queries.py`, `genes.py`, `qc.py`) accept both layer names; `cnv.normalise()` already treated row-max < 30 as log2 scale, so Phase 3–5 results are unaffected.
2. **Sample-level QC gate (DQ-03).** New flag `sample_qc_pass` (obs and `qc_per_sample.csv`): median detected genes of the sample's `qc_pass` cells ≥ 500 (`configs/qc.yaml sample_gate.min_median_genes_pass`). Flag only — nothing is dropped in Phase 2. **Flagged: okada__1734_pons (8,486 passing nuclei, median 427 genes / 468 UMI; next-lowest Okada sample 586_pons has median 971), scpca__SCPCS000637 (441 cells, median 362 genes) and scpca__SCPCS000636 (0 passing cells).** The two ScPCA samples were already dropped by Phase 4; 1734_pons entered the atlas input (8,466 nuclei, 2.7 % of the reference) and is now flagged for the integration track to exclude or re-check.
3. **Liu annotations and MT genes (DQ-04).** The Liu raw files come in **three** annotations, not two: 23,686 genes (16 samples), 32,617 (20 samples) and 55,765 (6 samples). The 16 samples on the 23,686-gene annotation (AAA007653, BT1179, ICGCGBM27, ICGCGBM60, ICGCGBM96, MUV16, MUV82, R1E1E3G3, S1D2E3H7, SUDIPG31, SUDIPG55, SUDIPG65, XT8698, XT9824, pTG4, pTG5; all frozen nuclei, 5,375 cells) **contain no MT- genes**, so the mitochondrial filter never acted on them; this is now recorded per sample as `mt_genes_present = False` and `qc_mito_rule = 'smartseq2 (inoperative: no MT- genes in annotation)'`. Decision 7's "only Filbin / LaBelle lack MT- genes" is corrected accordingly: 34 samples lack MT- genes (9 Filbin, 9 LaBelle, 16 Liu).
4. **Nuclei mito rule for Liu frozen nuclei (DQ-04).** With `author_prep_aware: true`, Smart-seq2 samples whose manifest chemistry is "frozen nuclei" and whose annotation carries MT- genes use the nuclei threshold (pct_mito < 5 %; min genes stays 1,000). This applies to **8 samples** (MGH6666410, SUDIPG30, SUDIPG45, SUDIPG50Aut, SUDIPG50Bio, SUDIPG54, SUDIPGIII, pSCG1): passing nuclei 2,405 → 1,743 (high-mito failures 569 → 1,297). Liu total `qc_pass` 13,100 → 12,438; **atlas headline 357,061 → 356,406 qc_pass (84.8 %)**; out-group unchanged (99,360). Liu is projection-only, so the reference models are unaffected; the Liu query set of Phase 5 changes and should be re-mapped by the mapping track. The remaining QC confound (16 unfiltered MT-less samples vs 8 mito-filtered frozen samples vs 18 fresh-cell samples) cannot be removed and is now disclosed here and in `qc_report.md`.
5. **LaBelle within-sample join (DQ-09).** Tumour and immune SS2 tables of P1–P8 are now combined with an outer join (zero-filled) instead of an inner join that discarded 4,736 measured immune genes. var carries `measured_in_tumor_ss2` (14,489 harmonised genes), `measured_in_immune_ss2` and `measured_in_immune_tenx` (19,112 each): a gene absent from the tumour table is zero for tumour SS2 cells although it is "measured" in the sample — use these flags, not `measured_in_all_samples`, when selecting genes for LaBelle. LaBelle `qc_pass` 8,240 → 8,247 (immune cells gained detected genes). Because `measured_in_all_samples` for LaBelle now equals the union, the "genes shared by all 10 studies" statistic rises from 14,119 to 18,301; the 18,882 UMI-study set is unchanged.
6. **Scrublet numbers (DQ-06).** Correct per-study median auto-thresholds (95 UMI samples): ScPCA 0.19, DeSisto 0.28, multiome 0.38, Zang 0.38, scRNA 0.39, Okada 0.42, Collot 0.51 (no study at 0.63); 36 of 96 UMI samples (37.5 %) had 0 auto-called doublets (35 with an automatic threshold, 1 where scrublet was skipped for < 100 cells; re-derived from qc_per_sample.csv) — "most samples" was wrong. The fixed-threshold rates (0.1–2.6 % per study) stand. Doublets remain likely under-called; calibration is deferred to the metaprogram/integration tracks.
7. **Wording (DQ-12, DQ-20).** Our `pct_mito` agrees with the authors' `percent.mito` within 0.32 percentage points (scRNA; 0.21 pp out-group; exact for multiome), not "to 2 decimals". The nuclear protocol of the six high-mito samples comes from Table S1 column `scRNAseq`, not from the author `Technology` column (which is 'sc/snRNAseq' for every GSE210567 sample). Decision 3 should read: the canonical symbol per Ensembl ID comes from the highest-priority source in `genes.py` (GRCh38-2020-A first, as a completeness rule), not from the "newest" source.
8. **QC figures (DQ-13).** `qc_violin_filbin.png` / `qc_violin_labelle.png` now show only the genes panel (counts and % mito carry no information for TPM/log-scale cohorts); every figure draws the per-sample thresholds (dashed min-genes / % mito, dotted 99.5th-percentile cap) and studies with > 24 samples use two rows. Samples without MT- genes appear as flat % mito markers in `qc_violin_liu.png` (see point 3). 300 dpi, no in-panel text.
9. **Not changed (documented, see docs/audit/fixes_data_repro.csv):** QC metrics are still computed on each deposit's native feature space before harmonisation (DQ-10); the 99.5th-percentile max-genes cap is kept as an intentional, documented 0.5 % trim (DQ-11); Okada's 10 Seurat-deduplicated symbols (`TBCE.1`, `MATR3.1`, …, 0.01 % of counts) are still dropped (DQ-08) and `pct_ribo` still uses prefix matching (DQ-18) because fixing them requires re-ingesting all UMI studies, which this remediation did not do.
